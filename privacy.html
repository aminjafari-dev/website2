Privacy

Privacy note

This note describes the Byto.tech website operated by Byto.tech GmbH, Großenbaumer Str. 143a, 45481 Mülheim an der Ruhr. Questions about it go to hello@ajo.company.

What this site is

The pages are static HTML, CSS, images, and a small amount of JavaScript that runs in the browser for animation. There is no account, no on-site form, and no analytics product installed in this repository. The site does not set its own tracking cookies.

Server logs

Whoever hosts byto.tech may store ordinary server logs when a page is requested: IP address, date and time, the URL, and the user agent. Those logs are a function of the host, not of a form on these pages. Ask hello@ajo.company which host is in use once the domain is pointed at one.

Google Fonts

Pages load the Manrope typeface from fonts.googleapis.com and fonts.gstatic.com. Opening a page sends your IP address and browser details to Google so the font files can be delivered. That request happens because the font link is in the page head.

Email and messengers

The mail link opens your own email program to hello@ajo.company. Phone links dial +49 176 89099964 or +374 93889073. WhatsApp and Telegram links leave this site and open those services with a draft message. What happens after that is covered by WhatsApp or Telegram, not by this page. The site does not receive a copy of the messenger conversation.

Work page storage

The homepage and work page write a small return-position note in sessionStorage under the key byto:return so the homepage can reopen the services or contact section. That value stays in the browser tab session and is not sent to Byto.tech.
