# PART A — Structure, brand & Instagram carousel style

Read this section before designing any slide. Part B (below) is the per-image brief.

---

## A1. What this carousel is

**One job:** Make a stranger understand Byto.tech’s brand promise in one swipe-through — *AI is fast; Byto makes what you ship secure.*

**Thesis:** Anyone can generate an app with AI. Byto combines AI speed with senior engineering and cybersecurity so products launch fast **and** defensible.

**Audience:** Founders, product owners, and teams tempted to “vibe-code” straight to production.

**Story arc (structure):**

```
Cover → Map → Problem → Risks → 3 Pillars → Contrast → Domains → Journey → Invite → Hard CTA
```

That mirrors the reference carousel’s rhythm (hook → menu → deep dives → process → handshake → close), adapted to Byto — not to an SMM agency.

## A3. Instagram carousel style (how the set should feel)

### Format & posting
- Upload as a **carousel** (multi-image), not a single post.
- Each frame: **1080 × 1350**, sRGB, PNG or high-quality JPG.
- Naming: `byto-carousel-001-ai-secure-01.png` … `-12.png`
- Viewer should understand the offer by **slide 3** without reading the caption.

### Visual system (Byto, not the reference agency)

| Token | Hex | Role |
|-------|-----|------|
| Navy deep | `#0F1E3F` | Dark slide backgrounds |
| Navy mid | `#213A56` | Secondary dark / charts |
| Cream | `#F5F0E8` | Light slide backgrounds |
| White | `#FFFFFF` | Text on dark |
| Gold | `#CDAA80` | Accent, CTAs, highlights, underlines |
| Bronze | `#997953` | Supporting accent, graph lines |
| Black | `#0A0A0A` | Text on cream when max contrast is needed |

**Typography:** Bold geometric sans for headlines (Space Grotesk / Satoshi / similar). Huge type. Mix **white + gold** on dark slides; **navy + bronze** on light slides. Body max 1–2 short lines unless checklist.

**Logo:** Byto.tech mark, **top-left every slide**, same size/position. Safe margin **80 px** from edges.

**Imagery language:** Classical craft × modern tech — greyscale statue with modern props (phone, padlock, glasses), glossy 3D icons (lock, shield, laptop, rocket), soft torn-paper edges, navy/cream blobs. One dominant visual per slide.

**Rhythm:** Alternate **dark → light → dark → light** so each swipe feels like a new beat.

**Hierarchy:** One huge headline → one support line → optional small list → visual does the rest. No card grids. No emoji in headlines.

**CTAs:** Gold rounded rectangle buttons; navy or white label text. Soft CTA on slide 01; hard CTAs on slides 11–12.

### What we borrow from the reference (structure only)
1. Bold cover with hero figure + soft CTA  
2. Light “map” slide with pills/list  
3. Dark hook slides with statue/modern twist  
4. Light icon slides (megaphone → our shield/rocket equivalents)  
5. Checklist / tablet strategy slide  
6. Torn-paper brand line slide  
7. Laptop / analytics craft slide  
8. Journey graph slide  
9. Hands / invite slide  
10. Final playful-but-premium CTA slide
